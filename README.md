# FGC — گزارش کار روزانه

نسخه اولیه رابط وب برای ثبت گزارش‌های روزانه شرکت Fared Group Company.

## امکانات فعلی
- رابط فارسی راست‌چین با تم سبز زیتونی
- انتخاب تاریخ و نمایش تاریخ شمسی، امکان رفتن به روز قبل/بعد
- ثبت ساعت ورود و خروج و محاسبه خودکار مدت کار
- ثبت و جمع واریزی‌ها (بدون بخش هزینه)
- شرح کار و افزودن عکس
- مشاهده و ویرایش گزارش‌های ثبت‌شده در همان مرورگر
- ورود نمایشی مدیر و همکار

## ورود نمایشی
- مدیر: `admin` / `123456`
- همکار: `hamkar` / `123456`

**این اطلاعات فقط برای آزمایش رابط کاربری هستند. این نسخه ورود امن واقعی ندارد. رمزها را عوض نکنید و اطلاعات حساس یا واقعی وارد نکنید.**

## محدودیت مهم
این نسخه فقط از `localStorage` مرورگر استفاده می‌کند؛ اطلاعات بین دستگاه‌ها و همکاران همگام نمی‌شود و ممکن است با پاک شدن داده‌های مرورگر از بین برود. برای استفاده واقعی باید به سرویس احراز هویت و پایگاه داده ابری متصل شود و دسترسی مدیر/همکار در سمت سرور کنترل شود. تاریخ ورودی فعلی از انتخابگر تاریخ دستگاه می‌آید و معادل شمسی آن نمایش داده می‌شود.

## انتشار
فایل `index.html` و گردش‌کار GitHub Actions برای انتشار GitHub Pages اضافه شده‌اند. وضعیت انتشار را در بخش **Actions** مخزن بررسی کنید. اگر Pages هنوز فعال نشده باشد، از **Settings → Pages** گزینه **GitHub Actions** را به‌عنوان منبع انتشار انتخاب کنید.
